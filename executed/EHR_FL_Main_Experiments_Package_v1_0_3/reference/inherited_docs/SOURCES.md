# Source basis (reviewed 8 September 2026)

## Project-derived protocol and executable inputs

- `reference/pilot_run_matrix.csv`: original TIMING-1..3 rows (B-C, C-B, B-C),
  Reference, same seed, 256 training / 128 validation per client, six rounds.
- `reference/pilot_settings_v1_1.json`: timing repetitions and warm-up; measurement
  clock, boundary and no-double-counting policy. Historical environment/schema
  placeholders are superseded by accepted evidence, not silently treated as final.
- `reference/pilot_membership.csv`, `reference/smoke_training_departments.csv`:
  byte-preserved original subset. Six-round Reference schedule is generated by the
  existing derived-seed/permutation rule before measured execution.
- Accepted full-size source ZIP and report are pinned in `config/timing_policy.json`.
- Accepted environment, model/PRG source identities and unchanged source checks are
  preserved in `reference/accepted_bc/` and `reference/unchanged_numerical_source.json`.

## Verified external implementation sources

- Python time module: `perf_counter_ns()` and `process_time_ns()`.
  https://docs.python.org/3/library/time.html
- Flower v1.22.0 `DefaultWorkflow`: fit/evaluate workflow injection and round order.
  https://github.com/flwrlabs/flower/blob/v1.22.0/framework/py/flwr/server/workflow/default_workflows.py
  Git blob: d12b181edd64eeded63870946853da324c4c8f64
- Flower v1.22.0 `message_size_mod`: sums each `record.count_bytes()` before and
  after a client callback. This package adopts that *content-accounting* definition
  and does not claim these counts are real transport bytes.
  https://github.com/flwrlabs/flower/blob/v1.22.0/framework/py/flwr/client/mod/comms_mods.py
  Git blob: 6d7fd9dba90577eecabc6a2a1a717ac1012d437d

The per-run median, descriptive-only summaries, two-end byte reconciliation and
explicit nested timer boundaries are new measurement implementation decisions
stated in `TIMING_ACCEPTANCE.md`, not retroactively attributed to a source paper.
The upstream PRG is neither redesigned nor upgraded in this timing package.
