## Evaluator
Training cannot call the final source loader. `Evaluate` first checks a separate receipt bound to campaign/source and the complete30 selected-model/calibration manifest. Only then is the supplied original11-table source checked against its fixed hashes. The shared approved feature routines encode final events without vocabulary/scaler refitting. Entity/event IDs and labels are join/order fields only, never model inputs. Sessions remain whole; unknown/missing coverage is reported without data deletion or vocabulary expansion.

Exact one-to-one labels/scores are required separately for held-out(primary) and known(secondary) tests: missing, duplicate, foreign-client and cross-partition rows cause failure, not silent inner-join filtering. AP is sklearn Average Precision, not accuracy or trapezoidal PR area. Threat positive; no class balancing. Pooled global AP/AUROC use concatenated validation-client-calibrated scores; raw global ranking metrics are fixed secondary diagnostics. Per-client metrics use raw scores. Missing either class yields undefined AP/AUROC; undefined denominators are null with counts. With actual positives and no predicted positives, precision is undefined and F1 is0. Worst-client AP is undefined if any client lacks both classes; retain minimum-client identity otherwise. Scenario subgroups report confusion counts, not standalone threat-only ranking metrics.

For each condition/test, show all five seeds, mean, sampleSD, median and range. Paired B−A and C−B contrasts are matched by seed. Only primary global/worst-client AP mean differences receive the adopted exploratory t95 interval(df4), all five finite pairs required and zeroSD interval suppressed. Other endpoints descriptive. No p-value, equivalence/non-inferiority claim or dataset/session resampling. Intervals describe algorithmic seed variability conditional on this fixed benchmark, not new hospitals. The inherited0.02 AP value is a practical reference only. Sensitivity thresholds are never ranked to choose a winner.

A future failed/repeated final evaluator run cannot be treated as an untouched hold-out. The status marks prospective test access and retains partial files. Original structural test exposure is acknowledged; unreported outside scoring remains unconfirmed. No script supplies a false negative declaration.

## Security and failure boundaries
Unchanged pinned local HMAC PRG patch, all3 clients at every accepted C stage, and existing loopback/version/FAB/cleanup controls remain. No secret/pairwise-mask/private-update values are added to exports. Evaluation metrics, calibration and counts are outside the model-update protection scope. Same-machine researcher orchestration and JSON/hash receipts are not OS isolation, digital signatures, remote attestation or active-server protection. The empirical guards and source review are not a formal cryptographic audit. Publication, licence and source-generator limitations remain explicit.

No automatic retries. `TrainNextBlock` runs only the next complete planned block; completed or partial attempts are never silently reused. One reviewed transient-infrastructure repeat of the entire block is permitted with exactly the same seeds/data/config, and both attempts retained. Unknown RuntimeError and code/permission/numerical errors are not retry-eligible. Timeouts require a documented transient cause; slowness in a completed run or an unfavourable metric is not a failure. A hard interruption leaving RUNNING needs review, not automatic recovery.
